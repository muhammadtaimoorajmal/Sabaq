# Findings

Generated research reports.

| Report | Produced by | Status |
| --- | --- | --- |
| `survey-analysis.md` | `npm run research:survey` from [`data/survey/responses.csv`](../data/README.md) | Appears once survey responses are committed |

The survey report contains the respondent breakdown, a verdict for each hypothesis with the observed value of every pre-registered criterion, a chart and table for every question, all open answers with citable references (for example `R12-Q25`), and a list of any data problems. Results below the planned 30 responses are marked as provisional.

Reports are generated, so they are never edited by hand: fix the data and run the command again.

# User Research

Sabaq is designed from evidence, not assumptions. This folder holds everything needed to run the research and, later, its anonymized results.

## Start here

1. Read the **[research plan](research-plan.md)**: questions, hypotheses, methods, participants and schedule.
2. Read **[consent and privacy](consent-and-privacy.md)** before contacting anyone.
3. Pilot the interview guide with one person, then begin fieldwork.

## Instruments

| Instrument | Who | Time | Answers |
| --- | --- | --- | --- |
| [Student interview guide](interview-guide-students.md) | 5–7 students | 30–40 min | RQ1–RQ3, RQ5, RQ6 · H1, H2, H3, H5 |
| [Instructor and class representative guide](interview-guide-staff.md) | 2–3 senders | 25–35 min | RQ1, RQ3, RQ4, RQ5 · H4 |
| [Contextual inquiry guide](contextual-inquiry-guide.md) | 2–3 sessions | 45–90 min | RQ1–RQ3, RQ5, RQ6 |
| [Survey](survey.md) | 30+ respondents | ~6 min | H1–H5, RQ6 |

## Data

Anonymized fieldwork goes into [`data/`](data/README.md). **Status:** fieldwork in progress; no data committed yet.

## Fieldwork checklist

- [ ] Interview guide piloted and adjusted
- [ ] Survey built and published
- [ ] 5–7 student interviews completed
- [ ] 2–3 instructor or class representative interviews completed
- [ ] 2–3 observation sessions completed
- [ ] 30+ survey responses collected
- [ ] 20+ artifacts collected and redacted
- [ ] Variety check in the participant register passed
- [ ] All data anonymized and committed; offline key stored safely
